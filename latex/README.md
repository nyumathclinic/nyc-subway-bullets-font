# nycbullets — New York City Subway route bullets for LuaLaTeX

```latex
\usepackage{nycbullets}
Take the \nycbullet{F} or \nycbullet{Fd} train.
```

The package typesets the route bullets of the New York City Subway in full
color with LuaLaTeX, and in monochrome with XeLaTeX. It uses the
accompanying OpenType color fonts `NYCSubwayBullets-*.ttf`. Their artwork
comes from the public-domain collection on Wikimedia Commons:
<https://commons.wikimedia.org/wiki/Category:New_York_City_Subway_bullets>.

See `nycbullets.pdf` for usage and the full list of bullets.
